# 2AI 静态语料方法与结果

`analyze_corpus.py` 只读取已保留的 `programs.json.gz`、独立全量统计及动作表；输入字节的 SHA-256 写入 `corpus-summary.json`。没有执行参考 ELF、启动脚本、VM 或包内业务代码。动作表用于来源导航，其哈希也被冻结；操作码语义仍须由原生证据证明。

## 复现

```sh
python3 docs/stage2ai-evidence/analyze_corpus.py
python3 -m unittest discover -s docs/stage2ai-evidence -p test_analyze_corpus.py -v
```

默认命令重算并逐字节核对两个 JSON；输出缺失、计数、样例位置、输入哈希或任意字节改变时失败，不自动修复。显式 `--write` 只重建本目录的 `corpus-summary.json` 与 `corpus-examples.json`。其余文件不写入。程序数、普通函数数、隐藏函数数、总指令数及七条操作码总数同时与独立 compatibility-summary 对照。

本次上述只读核对通过；显式重建后再次只读核对通过。9 项 Python 合成回归测试通过，覆盖七条操作码计数、重复位置、相邻来源、全部段种类与精确偏移、排序确定性、错误节点及画像、独立基线损坏、默认不写入、过期输入哈希与伪样例偏移检测。

## 结果

完整语料为 7,159 个程序、101,592 个普通函数、0 个隐藏函数、6,474,773 条指令。选定指令共 125,747 个静态位置。

`preceding_origin` 按前一条物理指令分类，`preceding_pair` 按前两条物理指令分类。常量类区分短整数、metadata 数值、metadata Real、共享字符串池索引及 Undefined；槽类区分 local/global/object，其他指令统一保持未知。共享字符串池索引紧邻所选操作码的次数分别为 01=4,069、1c=4,450、2a=4,020、1e=1、20=1、25=1、27=0。**这些不是 Bytes 运算次数，也不是已解析的左右操作数。**

## 样例定位与边界

96 个样例按程序 source 排序，在每个 opcode / Object 或 Global / init、functions 或 hidden / 前一指令来源组合中，保留首个程序、段与 PC。每条保存程序成员 SHA-256、函数名与槽号、代码段偏移、节点区偏移、PC，以及 `member_node_offset = nodes_offset + 4 * pc`；这是解压后的成员内部偏移，不是压缩包偏移。邻接窗口保存前两条、当前条和后一条指令及各自成员偏移。原始 par16/par8 保持有符号形式，不解读成运行时 tag。

程序身份由 source 和成员 SHA-256 共同定位；函数列表顺序取保留解析器结果。默认校验重算所有样例，故改动成员身份、PC、偏移、窗口、输入哈希和数量都无法通过逐字节校验。未保存全部 125,747 条 occurrence 明细，避免生成大转储；完整位置可由同一冻结输入重新枚举。

仅有物理邻接，未进行 CFG、跳转入边、栈效果、别名、跨调用值来源或动态可达性分析。局部变量、参数声明和相邻字符串常量都不证明执行时类型。init 的指令存在不代表 Rust 已开放 init 运行，也不改变本批普通函数实施设计边界。此前保留语料中的 DBA LZSS 异常由全量只读比较单独验证，本脚本不重新解压业务包、不绕过既有异常政策。
