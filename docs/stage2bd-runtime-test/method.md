# Acceptance method

Current validation starts from 865 baseline files. 857 remain byte-identical; six Rust sources permit test hooks and README/roadmap permit only a prefix preserving the complete old suffix. The reference artifact, models, evidence and old receipts remain frozen. Legacy test bodies are compared as tokens and all 705 baseline Rust scenario names must pass in both profiles.

vm_diff.py synthesizes ten small programs and seventy command checkpoints. A pinned 2BA World receives declared lifecycle events, independently of observed Rust counters. Expected real frame Object/function pairs are stated in the fixture timeline, including Global frames. Rust compares states, ordinary refs, exec refs, cleanup flags, LIFO queue, actual frame layout and resident records at each checkpoint, then checks actual record and store-control Weak probes after teardown.

Bounds are two objects, two Function heads, two container heads, three frames, sixteen owning slots, depth three and at most one thousand requested synthetic instructions per case. The shared lifecycle oracle contains only the supported scalar/Function slice; container graph validation is separate evidence. Scalar stack slots are outside the ordinary-reference projection. No new exhaustive domain, whole-VM proof, native instruction execution or business bytecode execution is claimed.

Direct unit tests additionally exercise borrowed drain/cleanup rejection, script catch, sticky failure/restart, lease rollback before failed call commit, direct method calls, queue capacity reservation, real container construction, a retained completion shell, closed-epoch late slot release, missing frame binding corruption and freed-ID anti-resurrection. Explicit safety points alone drain/reap; budget/return/error/cancel/extraction do not silently drain.

Current reference_replay.py reexecutes 2BC's eighteen traces/146 steps and 2BB's 14948 attempted transitions, saving reports and actual logs only under 2BD. Old generators, reports and model bytes are not changed.

Historical validation preserves two authorities. A local shared clone at 1306a9b runs the 25 original 2BC Python tests and its read-only receipt. Its unchanged historical.run() separately clones 7a21530 and reruns the older 267 Python tests. This produces 292 historical checks, never advertised as passing against the modified current source. Eleven legacy CRLF files are restored in temporary clones only from verified baseline bytes with identical normalized contents. Neither old verifier is relaxed.

Full receipt generation runs current Rust debug/release tests and unchanged doctests, ordinary production builds in both profiles, fmt, strict clippy, all three separate workers and current Python validators. Logs record actual arguments, statuses and output. The 2AW corpus result is reused by exact frozen hash with rerun=false. No reference executable, real service or business program is run.
