# 2AM 能力增量与剩余边界

基线为2AK运行时与2AL取证；本表补充2AH等历史矩阵，不重写冻结文件。

| 能力 | 2AM状态 | 验证/限制 |
|---|---|---|
| Int/Bytes Mapping哈希与桶链 | 实现 | 原始hint、首NUL/32字节哈希、全长相等、头插、空桶预算、扩容子链反转 |
| 公开容器访问 | 保持兼容 | entries位置顺序、最后覆盖、get结果及既有成员Cell身份不变 |
| 普通函数Mapping997 | 受限实现 | 实时bucket/subindex扫描、ordinal、输出三元数组复用；已有Local/Object/Global绑定 |
| 暂停、调用和清理 | 已支持范围回归 | 单步预算、嵌套/递归、返回/restart与既有数值catch；新增错误来源不可捕获 |
| 失败原子性 | Rust策略 | 可报告分配/借用/跳转/readonly失败不部分写入；内部PC预推进、诊断原PC |
| G05 | partial | 其他键/属性、删除后成员引用与节点回收、复杂别名仍未闭合 |
| G06/G07/G17及相关门槛 | 仍开放 | 无环模型、成员标量写、复杂引用/槽/任务限制未放宽 |
| 公开删除/清空、生命周期循环 | 继续拒绝或无入口 | 本轮不实现真实efun、初始化/构造任务或默认表达式循环 |

515项Rust测试：71单元、23解析、421 VM；新增28项并修订1项旧拒绝断言。19项Python静态模型/语料测试。操作码支持仍为75，主语料交集仍为73；Mapping分支扩展不会增加编号。阶段2尚未完成，未作真实业务执行等价声明。
