# 阶段 2H：固定函数的引用参数运行时

## 总体结果

已在 Rust VM 中实现当前对象内固定参数函数的引用传递、读取、写穿透及嵌套转发。沿用既有 52 种 opcode，没有新增公共类型、API、Cargo 依赖或 unsafe。公共 `Value` 仍不包含 Reference。验证仅执行内存中人工构造的程序，没有执行参考 ELF、启动脚本或业务字节码。

依据是[阶段 2G 的原生函数、地址和语义](vm-reference-arguments.md)及其 [REA/Ghidra 证据索引](vm-reference-arguments-evidence/index.md)，本轮复用这些证据，没有新开 Ghidra 会话。原始观察与 Rust 的兼容策略分别说明如下。

## 一、支持范围与接口

- 只接受 Magic559、单 constitution、无继承、当前对象的固定参数函数；仍不支持默认参数、可变参数、atomic、const、全局调用及跨对象调用。
- 参数 flag 仅允许 0/1，attrib 仅允许可空位 8，类型支持 0/1/2/3/4/6/7/10/255；拒绝未知位。含引用参数的函数必须以 `0f` 开头。
- `Vm::start(object, function, Vec<Value>)` 不接受引用参数根入口，返回 `UnsupportedFeature`。通过普通入口函数的 `39`、`3e` 或成员/临时引用构造及 `07` 调用建立内部绑定。
- 原 Reference 直接保留在参数槽中，Cell ID、Frame/Object 拥有者、ReferenceKind、readonly 和额度凭据均不改写。局部引用仅接受源帧声明的参数、局部变量，求值槽来源返回 `UnsupportedFeature`。

| 指令 | 本阶段行为 |
|---|---|
| `07` | 预检参数数量、绑定种类、引用有效性、局部来源和帧限额；成功后创建调用帧 |
| `0f` | 在执行时重新检查实际类型，整批成功后提交转换及归一化 |
| `37` | 读取引用参数目标，产生普通 Value |
| `39` | 对引用参数克隆原引用，支持转发与别名 |
| `4d` | 对引用参数写穿透，RHS 留栈，不重新约束声明类型 |
| `14` | 显式引用读取；成功时归一化死对象源 Cell |
| `03/04/4d/22/2f` | 共用拥有者、readonly 和成员标量写入限制 |

普通标量参数仍按值隔离，Array/Mapping 的值克隆保留共享容器身份，并不深复制。入口声明类型只约束检查时的目标类型，之后允许通用赋值改变类型。

## 二、参数原子检查与兼容差异

原生 `vm_checkArgNum @0x0809521c` 按序产生副作用，失败前可能已转换普通参数或清理引用目标。根据已选定策略，Rust 使用不同的失败语义：

1. `07` 失败保留调用者操作数栈、目标 Cell 和调用帧集合。
2. `0f` 先读取并检查全部参数，暂存修改，按 Cell ID 合并重复目标；获取所有写入借用后才批量提交。失败不发生部分修改，保持该指令入口的操作数及目标值。
3. 普通参数保留数值转换；引用参数要求精确类型匹配，不转换 Int/Real。可空类型接受 Undefined；typed 引用的已销毁对象按 Undefined 检查，仅整批成功后清理源 Cell。
4. mixed 引用仅检查引用有效性，跳过目标类型及入口归一化。`07` 与 `0f` 间预算暂停后，宿主删除对象会在恢复时重新检查。

原生普通 mixed 可以携带 Reference，原生 mixed 返回也可能保留 Reference；Rust 本阶段均拒绝。引用不能进入返回值、容器或对象变量等持久存储。错误种类按情况使用 `UnsupportedFeature`（不支持的绑定）、`UnsupportedType`（类型不匹配）、`ArgumentCount`、`InvalidState`、`InvalidObject` 或 `Limit`，执行错误保留源文件、函数、PC 和偏移。

这是受限兼容实现，不是全量行为等价。静态统计中的 3,050 个形状候选函数未作为业务程序执行，也不能据此计为已经支持。

## 三、生命周期与资源

正常返回先检查结果并准备结果槽，随后清理被调帧参数和局部槽。清理引用参数释放其凭据，调用者继续拥有原 Cell；成员和临时引用沿用已有强持有及限额规则。同一 Cell 多个引用共用额度，正常返回后额度可复用。

函数体发生错误时，之前成功的写入保留，终止帧及引用用于诊断，在新一次成功 `start` 或 VM 销毁时释放。不模拟原生 catch/longjmp 的恢复和回滚。失效祖先帧不能复活局部引用，已删除对象不能因残留 Cell 被重新访问。

`37/14` 成功读取已销毁对象时同时清理源 Cell；`37` 在栈满时先失败，不产生清理副作用。普通非引用复制的既有行为不扩大修改。批量写入释放所有借用后才丢弃旧值，避免容器析构在借用期间清理成员槽。
