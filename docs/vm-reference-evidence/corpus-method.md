# 引用相关指令的静态使用统计

`corpus-usage.json` 直接读取既有 `docs/compatibility-evidence/programs.json.gz`，以 `docs/evidence/actions.csv` 映射操作码、入口地址及参数数目。两个输入的 SHA-256 写入报告。没有重新解压、执行业务字节码或启动参考 ELF。

## 方法

遍历每个已解析程序的普通函数、隐藏函数和初始化代码；只累计 `code.nodes` 中 `(par16, par8, opcode)`，不累计用于调试信息的 `runtime_hex`。每次出现计一条；程序数按完整 `source` 去重，代码段数按 `(source, 类别, 函数索引)` 去重。包名截取至 `.pak`，服务名取路径首段。

统计覆盖 7,159 个程序、101,592 个普通函数、0 个隐藏函数、108,751 个代码段及 6,474,773 个节点，并对程序、函数及节点总数断言检查。报告保留每条关注指令的完整原始操作数二元组直方图、各服务/包计数、段内前后相邻指令的前 20 名，以及前三个出现位置。位置为解压后的成员内偏移，不是 ELF 地址。

## 主要观察

- 普通赋值 `0x03` 出现 250,825 次，覆盖 5,233 个程序；反向赋值 `0x04` 出现 169 次。
- 局部变量引用 `0x39` 出现 278,565 次；对象变量引用 `0x3e` 出现 27,139 次；全局变量引用 `0x36` 出现 3,929 次。
- 成员引用 `0x44` 出现 39,649 次，覆盖 2,890 个程序；其中参数 0 为 39,639 次，参数 1 为 10 次。它紧邻普通赋值之前的情况有 33,193 次。
- 普通成员读取 `0x43` 出现 133,138 次，其中参数 1 有 174 次，不能因模式少见而忽略兼容性。
- `0x11`、`0x3a`、范围引用 `0x46` 和直接设置变量 `0x4c/0x4d/0x4e` 均未出现。
- 自增减 `0x22` 出现 4,239 次；复合赋值 `0x2f` 出现 17,336 次。其操作数含义须结合反编译确认。

## 解读边界

这些是序列化节点的出现次数，不是执行次数或可达性证明。同一库分发到多个服务包时分别累计。相邻节点没有进行控制流或栈来源分析；不能据此证明某次写入的容器类型、别名关系或引用生命周期。零次仅表明本语料未使用，并不证明原 VM 不支持该指令。对于无参数指令，原始操作数字节也不能解释为生效参数。
