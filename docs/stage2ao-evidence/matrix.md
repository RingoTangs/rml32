# 2AO 能力增量与剩余边界

以2AM运行时、2AN取证为基线；历史矩阵不改写。本表是能力增量，不是分支覆盖率。

| 能力 | 2AO状态 | 边界 |
|---|---|---|
| 函数值表示 | 已迁移 | 可选creator owner与Object／Global目标分离；公开owner/program返回Option |
| Global/c 17 | 受限实现 | 显式新入口，标量捕获，绝对槽查询运行时绑定，Object与Global创建者 |
| Global/c 05 | 受限实现 | 当前绑定须为保存程序；无对象callee，实际代码池／schema／诊断 |
| 绑定变化与暂停 | 受限实现 | 新调用拒绝clear／换绑，原帧继续；嵌套直接07查询当前绑定 |
| 旧能力及错误策略 | 保留并回归 | 旧入口仍只执行Object函数值；失败提交、引用lease、预算及既有数值catch |
| G12／G18 | partial | 本批Global用户函数值已实现；Host/K及继承／生命周期组合未闭合 |
| 第二批Host/K | 未实现 | 不增加Host目标或组合准备入口，不实现真实efun |
| 非标量捕获、GC、热更新、生命周期 | 仍排除 | 不以Rc共享或新入口绕过原有限制 |

544项Rust测试（78单元、23解析、443 VM），新增29项；27项Python检查（22项2AN可复用检查＋5项本批检查）。支持集合仍为75种，主语料交集73种；阶段2未完成。测试只执行合成程序，5,012处静态位置不代表业务执行覆盖。
