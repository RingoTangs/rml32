# Host/K 函数值运行时

阶段2AP增加受限的 `FunctionTarget::Host { slot }`。组合准备入口
`prepare_program_with_callable_values` 与
`prepare_global_program_with_callable_values` 显式开启普通Host调用、对象/Global
函数值、Global/c 与 Host/K。既有入口的能力范围不变。

公开 `FunctionTarget` 新增枚举分支，会要求对该枚举做穷尽匹配的调用方增加Host分支。
Host函数值的 `program()` 返回 `None`，`function()` 返回Host槽号，`owner()`保留可选
创建对象；这些访问器不查询当前Host注册。

17指令的 `par8` 按无符号位解释：`0xc0..=0xff` 选择Host/K，低六位表示0至63个
标量捕获；槽位必须在0至558。创建时要求槽位已注册，但函数值只保存槽号，不保存
回调或签名。每次05调用都读取当前注册，因此移除后调用失败，替换后使用新回调和
新签名。Host目标不依赖Global程序绑定，可由有或无活动对象的上下文创建。

05的顶部操作数是函数值，其下是新参数。已捕获参数先于新参数组成逻辑参数列表，
总数不得超过127。Host签名做数量和精确类型检查，不使用普通用户函数的数值强制
转换。回调上下文描述调用05的当前程序、对象、函数和指令位置；创建者只参与原有
删除检查，不改变调用上下文。

执行前VM检查参数形状、签名、容器深度和资源上限，并预留结果Cell与栈容量。回调
恰好调用一次；返回值通过声明类型及图结构检查后，VM才消费参数并推进PC。预检失败
不会调用回调。回调错误或返回校验失败会保留操作数和PC，但回调已产生的外部副作用
不会撤销，也不会自动重放。Host调用没有用户字节码帧，不暂停在回调内部；帧预算仍
按现有同步Host激活规则检查。

Host `Any` 和 `Mixed` 可以把函数值作为不透明值传递；当前不提供Host函数值专用类型，
也不允许把函数值装入捕获、容器或作为非Any精确类型参数。真实efun、异步回调、回调
重入及原生延迟删除语义仍未实现。测试只执行合成程序。
