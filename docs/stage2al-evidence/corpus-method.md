# 2AL Mapping / 循环静态语料导航

`analyze_corpus.py` 是 2AI 工具的独立副本，只读取保留的 `programs.json.gz`、独立 `compatibility-summary.json` 和动作表。三个输入的完整 SHA-256 保存在 `corpus-summary.json`；每条样例另存成员 SHA-256。未执行参考 ELF、启动脚本、VM 或业务字节码，也不重新解压业务包。动作表只冻结来源，不替代原生语义证据。

## 复现与校验

```sh
python3 -B docs/stage2al-evidence/analyze_corpus.py
python3 -B -m unittest discover -s docs/stage2al-evidence -p test_analyze_corpus.py -v
```

默认重算并逐字节比较两个 JSON，不写文件；缺失、过期、损坏即失败。只有显式 `--write` 才重建本目录 `corpus-summary.json` 与 `corpus-examples.json`。总程序、普通函数、隐藏函数、总指令和六个选定操作码的数量均与独立 compatibility 基线核对。

本轮显式生成后默认只读校验通过；9 项合成测试通过，覆盖重复位置、全部六条操作码、各段上下文、有符号节点及精确偏移、确定性采样、非法画像/节点、独立基线错误、默认不写入、输入哈希和伪造样例偏移。

## 定位与限制

按 source 排序，再按 init/functions/hidden、函数列表和 PC 顺序，针对每个 opcode / mode / 段种类 / 前一物理指令来源组合保留首条。每条保存成员身份、函数名和索引、段与节点区偏移、PC、原始有符号 par16/par8/opcode 以及邻接窗口。`member_node_offset = nodes_offset + 4 * pc` 是解压成员内偏移，不是压缩包偏移。默认重算逐字节核对会拒绝成员身份、节点、窗口、位置、来源哈希或统计的变化。

前一条与前两条指令来源分类只是物理邻接；没有进行 CFG、跳转入边、栈效果、别名、跨调用或类型分析。相邻建表、变量槽或字符串池索引不证明实际操作数、运行时类型、Mapping 键类型或游标源。完整位置可从冻结输入重算，不提交全部 occurrence 大转储。既有 DBA LZSS 异常处理仍以独立全量兼容性证据为准，本脚本不改变其政策。
