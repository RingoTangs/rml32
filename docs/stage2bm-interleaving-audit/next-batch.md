# 下一批建议

2BM 已补充对象状态转换与已准备事务交错，下一批可独立规划多个同时在途事务的竞争提交：两个计划共同观察源／目的槽，交叉 commit/abort、Function 预留和执行预留，重点检验第一次提交后的版本失效、资源峰值和第二次失败的精确归还。当前单个 CopyPlan 和单个未发布 Function 槽不能作为多事务覆盖。

公开 VM 仍为同步指令提交；内部交错不是公开并发接口。另一条独立工作仍是使用获授权的现成环境做真实 32 位回归，或对 20 项 native unknown 的精确剩余前沿取证。本批结果不自动开放直接捕获、implementation_ready 或阶段2门槛。
