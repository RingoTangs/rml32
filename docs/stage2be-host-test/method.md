# Acceptance method and evidence limits

The baseline contains 893 files. Five sources allow test hooks: boundary, object, VM, lifecycle adapter and lifecycle runtime. README/roadmap permit a prefix only, retaining the full baseline suffix. The other 886 files remain byte-identical, including the reference ELF, all old models, Rust fixtures, native evidence, old receipts and preparation code. The new Rust fixture is reachable only through a cfg(test) boundary module.

The pinned fail-closed source projector removes supported test-only items, keeps cfg(not(test)) bodies and expands only the four established exact production factories. Production token streams of boundary/object/VM must match the baseline. Adapter/runtime remain inside the frozen test-only module gate. Original test token bodies and all 728 baseline ordinary scenario names must be preserved. This scanner is not a general Rust compiler proof; actual non-test builds run in both profiles.

Thirty-one new ordinary Rust scenarios exercise real public-boundary operations through a private constructor, including failure rollback and missing-root audit detection. All ordinary scenarios run in debug/release. Two unchanged compile-fail doctests retain their identities/bodies; source line offsets move because boundary hooks were inserted. Four ignored timeline workers are separately executed and checked, never treated as skipped ordinary coverage.

host_diff.py declares twelve synthetic program timelines with seventy-five checkpoints. The frozen 2BA model receives explicit events independently of Rust output. Each checkpoint checks object state, refs, execs, cleaned flag, queue, physical record residency, actual Registry root/retirement counts, close flag, frame depth and callback count. Every case verifies final record, Registry and StoreState Weak probes expire. Bounds are two Objects, three frames, sixteen projected owning slots, eight Host roots and at most one thousand requested instructions per trace. No new exhaustive domain or full-VM/native equivalence is claimed.

The common trace projection contains Object/scalar roots; Function creator and container graph cases are additional real Rust unit evidence. Raw invalid Host retention is checked by explicit Rust assertions, not the model's source-normalizing copy event. Closed-store physical retention is a separate probe assertion: model close alone never proves storage ownership. Final arena teardown does not promote model cleanup timing into a native guarantee.

The three frozen drivers rerun the prior ten traces/seventy checkpoints, eighteen traces/146 steps and 14,948 attempted kernel transitions. Their generators, old inputs and reports are unchanged; new actual logs and source hashes are saved here only.

Historical checks run in a local shared clone at d237bf3: its 24 Python checks and read-only receipt verifier execute there. Its unchanged historical.run() reexecutes the prior 292 checks under their pinned 1306a9b and 7a21530 authorities. Total: 316 historical checks, explicitly not current-source tests. Legacy CRLF bytes are restored only in temporary clones after verifying frozen hashes and identical normalized contents. No verifier is relaxed.

The receipt records actual command arguments, exit codes and stdout/stderr for historical checks, both Rust test/build profiles, fmt, strict clippy, Host replay, all three previous replays, source verification and current Python tests. Artifact hashes include all new delivery files and permitted source/prefix edits. The frozen 2AW corpus report is reused by exact hash with rerun=false. No reference program, business bytecode, network service or native analysis is run.
