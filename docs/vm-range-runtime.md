# 阶段 2Y：受限范围查询运行时

## 结果与支持范围

按[阶段 2X 规格](vm-range-semantics.md)实现 `45 vm_queryRange`，支持普通函数内的 Bytes/Array 查询，包括既有继承与跨对象调用。当前为 **69 种限定操作码**；主语料交集 67 种，缺 `05/06/10/17/35/36` 六种。没有新增公共类型、API、Cargo 依赖或 unsafe，CLI 继续只读检查制品。

新增 17 项 VM 集成测试、4 项内部测试，共 **344 项 Rust 测试**（22 单元、23 解析/CLI、299 VM）。全部执行输入为人工构造程序，没有执行参考 ELF、启动脚本或原始业务字节码。3,452 条静态范围指令的统计不代表执行覆盖；其中 12 条初始化指令仍被明确拒绝。

## 计算、复制与提交

栈从旧到新为 source、begin、end，成功后替换为一个结果。准备阶段接受 mode0..3、忽略 par8，拒绝其他模式；默认表达式与初始化代码不开放该指令，初始化/构造/回滚辅助函数在执行时也受生命周期检查约束。

区间为闭区间。mode bit0 对 end、bit1 对 begin 使用 `L-max(x,1)` 尾部计数，再裁剪 begin 下限0、end上限L−1；反向区间返回空结果。Int/Real 端点沿用 CVTTSS2SI 策略：截断，NaN/无穷/超范围得到 i32::MIN。内部使用 i64 算术，源长度超过 i32::MAX 返回 Limit，不把合法裁剪当越界错误。

Bytes 使用原生 String 的 strncpy 行为：选区内遇到 NUL 后剩余结果补零，长度保留；不做 UTF-8 解码，选区之前的 NUL 不影响结果。输出最多65,536字节，源可更长；超过输出上限返回 Limit。

Array 创建新的顶层槽，沿用现有65,536项、深度64、无环约束，嵌套容器继续共享。只将选中直接元素中的失效 Object 规范化为 Undefined，并同步更新源元素槽；未选中元素与嵌套失效对象不变。其他源数组别名能观察到该规范化，但对结果顶层槽的后续赋值不改变源槽。

实现先读取所有选中元素、构建结果，再按 Cell ID 去重，通过 `Cell::replace_batch` 一次提交源元素更新和 source 栈槽替换，随后移除两个端点。借用冲突、类型检查或结果验证失败不产生部分源更新，输入操作数保留；沿用原有指令前进PC及诊断定位方式。原生实数原地转换和 Array 提前弹栈的失败状态不同，这里采用明确的 Rust 提交前原子策略。标准库 OOM 终止和 Cell ID 消耗不提供回滚保证。

Rust 空数组结果有新身份，原生 `_nullArray` 共享头的身份规则未复制。字节输出上限也是受限实现策略，不是原生限制。

## 错误、预算和限制

不支持的普通值类型返回 UnsupportedType；直接 Reference 通过现有 value() 返回 UnsupportedFeature，不悄悄解引用。非法模式、默认表达式和生命周期上下文为 UnsupportedFeature；栈不足为 StackUnderflow，超限为 Limit，借用冲突为 InvalidState。错误由既有 run() 补全源、程序、对象、函数、PC、偏移和任务上下文；原操作数可由该位置查回 Instruction。

范围错误不标记 RuntimeFaultSite，即使周围有 catch 也仍然终止。重启后的数值除零继续按既有白名单捕获。一次查询消耗一个指令预算，不在复制中间暂停；零预算不分配、不规范化。生命周期拒绝进入既有任务清理或构造回滚，指令局部原子性不承诺任务栈和对象留存。

Buffer、Mapping/其他源类型、范围引用/写入、生命周期及默认表达式执行、任意错误捕获仍排除。没有扩大既有函数原型、访问控制或对象删除契约。
