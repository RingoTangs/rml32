# 2AP 能力增量与剩余边界

| 能力 | 2AP状态 | 边界 |
|---|---|---|
| Host/K函数值 | 受限实现 | 保存Host槽号；每次调用查询当前注册和签名 |
| 组合准备入口 | 已提供 | 同时开启对象/Global函数值、直接06和间接Host/K |
| 参数及回调 | 受限实现 | 最多127个标量参数；同步单次回调；不做用户函数数值强制转换 |
| 调用上下文 | 已验证 | 使用05调用者上下文；创建者仅参与生命周期检查 |
| 提交与错误 | 已验证 | 回调前完成预检和资源准备；回调错误不回滚外部副作用、不重放 |
| 函数值透明传递 | 受限支持 | Host Any/Mixed允许不透明传递；不支持精确Function类型或捕获函数值 |
| 原有能力 | 保留 | 旧准备入口不扩大；2AO Global/c 与直接06继续受原边界约束 |
| G12／G18 | partial | 本批Host/K受限语义已实现；继承／完整生命周期组合未闭合 |
| 阶段2 | 未完成 | 真实efun、异步／重入、GC及原生延迟删除仍排除 |

静态支持集合保持75种限定opcode，与主语料交集保持73种。语料中的指令位置不是
运行时覆盖率；验证只执行合成程序，不运行参考程序或业务字节码。
